# Frontend agent pointer

Project-wide contract: read `../AGENTS.md` (repository root) first — it is the single source of truth.
Next.js-version-specific rules generated by `next dev` live in `./AGENTS.md` in this folder.

Frontend-only conventions:
- UI is a demo surface. No model/planner logic in this package (root AGENTS.md §25).
- Palette is fixed to the Haas set in `src/lib/palette.ts`; do not introduce other hues (alpha blends of
  the four are fine; never additive/`lighter` canvas blending, which escapes the palette).
- The intro loader (`src/components/loader/`) is the page-load animation only — NOT the race simulator.
  CSS-driven parts animate only `transform` / `opacity`; the two `<canvas>` layers (rubber marks, smoke)
  are a deliberate exception with a per-frame JS budget of ~2 ms. Physics lives in `loader/physics/`
  (pure TS, vitest), canvas maths in `loader/effects/`, and `loader/runtime.ts` is the only file that
  touches both a `dt` and the DOM. Run `npm test` after touching physics or effects.
